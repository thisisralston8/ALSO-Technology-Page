BATTERY PAGE
============
Click a link on the right to play its sound; the circle reacts to the audio.
Click "Edit" (bottom-left) to change colours, the background reference image,
and to add / rename / remove links with your own sounds. Edits are saved in
your browser only.

RUN IT
------
The page must be served over http (browsers block it from file://).
You need Python 3 OR Node.js installed.

  macOS / Linux : double-click start.command  (or: ./start.command)
  Windows       : double-click start.bat

Then open http://localhost:4801/ (it opens automatically).
Stop the server with Ctrl+C in the terminal window.

Any other static server works too, e.g.  npx serve .   or  python3 -m http.server 8000
(use a modern browser: Chrome, Safari, Firefox, Edge).
